## 👨‍💻 About Me

I am a mobile developer who builds production apps for **Android (Kotlin / Java)**, **iOS (Swift / Objective-C)**, **Kotlin Multiplatform** and **Flutter**, with a strong focus on reactive, testable architecture.

- 📱 Native Android (Kotlin, Java) & iOS (Swift, Objective-C), plus cross-platform delivery with **Kotlin Multiplatform (KMP)** and Flutter
- ⚙️ Systems and native layers with **C / C++** (NDK, JNI) and **Rust**
- 🧩 Shared UI with **Compose Multiplatform** and modern Android UI with **Jetpack Compose** (see my [Compose runtime notes](compose_runtime/compose_runtime_slottable.md))
- ⚡ Passionate about reactive programming with **RxJava / RxSwift**, Kotlin Coroutines & Flow
- ✍️ I write about mobile development on my [blog](https://hoangchungk53qx1.github.io/blog/docs/index-page/)
- 🌱 Love contributing to **open source** — bug fixes, docs and features for the libraries I use every day
- 💼 Open to **freelance** projects via [Rx Mobile Team](https://rx-mobile-team.github.io/profile/)
- 📫 Reach me at **hoangchungk53qx1@gmail.com**
